比赛解题思路

节点wirestatenode，订阅jointstate，handsstate，发布当前线缆/机器人状态，分为
init，使用waypoint/加入障碍物将机器人的手臂放到桌子正上方，然后启动以下状态
1 机器人初始位姿准备状态 （识别到一个空余线缆+一个空余插口并记录位置）-》
2 机器人正在抓取抓取线缆状态 （腕部相机确认手捏住线缆）-》
3 规划线缆前往插口附近状态 （腕部相机确认成功）-》
4 返回初始位姿过程状态 （到位）-》1 

节点headdetectnode，订阅wirestate，发布插口和母口位姿，以及一个有效位，在非1&4状态下有效位为0

节点totalctrl，调用xrocs，订阅state，插口母口位姿，规划过去节点切换状态执行对应动作，和加载模型
