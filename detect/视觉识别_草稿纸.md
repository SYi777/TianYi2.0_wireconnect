## 3. 技术要点记录

### 3.1 图像传输加速
- 原图 `image_raw`: 1280×720 BGR8 = 2.8MB/帧 → DDS 序列化 + 网线扛不住
- 解决: 用 `/ob_camera_head/color/image_raw/compressed` (JPEG ~150KB/帧, 快20倍)
- `cv2.imdecode(np.frombuffer(msg.data), cv2.IMREAD_COLOR)` 解码

### 3.2 避免 cv_bridge 冲突
- ROS2 的 cv_bridge 编译时链接旧版 numpy，pip 装的新版 opencv 不兼容
- 解决: 不用 cv_bridge，直接 `np.frombuffer` + `cv2.imdecode`

### 3.3 模型
- YOLOv8n (3.2M参数), 迁移学习自 COCO 预训练
- 275张图, 单类(usb_a_port), 100 epochs
- mAP50=0.87, P=0.89, R=0.82
- GPU 3060 推理 ~5ms/帧, 30FPS 实时

### 3.4 TF桥接
- 机器人 URDF 和相机驱动是两棵独立 TF 树
- 必须手动加 `static_transform_publisher camera_link → ob_camera_head_link` 才能连通

## 4. 下一步: 深度→3D→抓取 (舍弃 PnP)

USB-A 母口在 1280×720 图上仅 10~15 像素 → PnP 不可行。
改为纯深度方案，依靠"母口朝上+工作台水平"简化：

```
detect_both.py → 母口 bbox 中心 (uc,vc) + 深度值 Z
  → 反投影 → optical_frame 3D 坐标
  → TF → waist_yaw_link 3D 坐标
  → XARM 笛卡尔控制 (endpose_single_arm_qp_L)
  → 无旋转 (q=[0,0,0,1], 手从上方垂直下抓)
```
