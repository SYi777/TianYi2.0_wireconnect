> **💡 当外部设备（例如 4090 主机、Thinkbook 数据采集笔记本）想要使用路由器通过有线/无线**
    的方式与天工/天轶 2.0 连接时，需要通过修改 DDS 配置才能成功读取到 ROS2 话题




> **⚠️ 以下内容提到的用户名、IP、文件路径等信息均为示例，具体内容请以实际为准**

## 1. 外部设备 DDS 配置

  假设（1）当前 Ubuntu 系统下用户名为 ps（2）当前设备 IP 为 192.169.31.10

## 1. 在 /home/ps/ 下解压  data.zip


## 2. 编辑 /home/ps/data/param/dds_profile.xml

   a. 在 <interfaceWhiteList> 字段下增加 <address>192.168.31.10</address>

## 3. 编辑 /home/ps/data/param/ros2_config.txt

   a. 修改 ROS_LOG_DIR、ROS2_BAG_DIR、FASTRTPS_DEFAULT_PROFILES_FILE 对应的文件路
      径
   b. 确保 ROS_DOMAIN_ID 设置为指定的 ID (在192.168.41.1上使用 echo $ROS_DOMAIN_ID 查看)

## 4. 编辑 /home/ps/data/param/ros2_setup.bash



   a. 修改脚本中的文件路径为本地目录（例如 /home/eai/data/param/ros2_config.txt 改为
      /home/ps/data/param/ros2_config.txt 等）

## 5. 在 ~/.bashrc 脚本末尾追加条件判断语句用于自动加载 ROS 2 环境配置

   a. [ -f /home/eai/data/param/ros2_setup.bash ] && source
      /home/eai/data/param/ros2_setup.bash

## 6. source ~/.bashrc
