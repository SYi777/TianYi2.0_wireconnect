## 1b. xarm_debug

```bash
source ~/WireConnect_ws/install/setup.bash

# 话题监控
source ~/WireConnect_ws/install/setup.bash && ros2 run xarm_debug xarmdebug

# 控制器交互管理
source ~/WireConnect_ws/install/setup.bash && ros2 run xarm_debug xarmcontroldebug
```

| 命令 | 说明 |
|------|------|
| `l` | 列出所有控制器 |
| `a <name>` / `d <name>` | 激活 / 停用 |
| `jL <7f>` / `jR <7f>` | 关节空间 (rad) |
| `jB <4f>` | 身体关节 (first_leg, second_leg, waist_pitch, waist_yaw) |
| `cL/cR <xyz qxyzw>` | 笛卡尔空间 |
| `mode <0-3>` | 0柔顺 1速度 2重力补偿 3位置环 |
| `arm enable` | 手臂硬件使能 |

## 4. 身体关节直控

| 话题 | 电机ID | 关节 |
|------|--------|------|
| `/head/cmd_pos` | 1-3 | roll/pitch/yaw |
| `/waist/cmd_pos` | 31-32 | yaw/pitch |
| `/leg/cmd_pos` | 51-52 | first/second_leg_pitch |

**身高 = waist_pitch (电机32)**，范围 -0.785~2.094 rad，正=后仰升高

```bash
# bodyctrl 直发
source ~/WireConnect_ws/install/setup.bash && ros2 topic pub --once /waist/cmd_pos bodyctrl_msgs/msg/CmdSetMotorPosition \
  "{header:{stamp:{sec:0,nanosec:0},frame_id:''}, cmds:[{name:32,pos:0.5,spd:4.0,cur:20.0}]}"
```

## 5. 灵巧手控制

```bash
# 读取状态
source ~/WireConnect_ws/install/setup.bash && ros2 topic echo /inspire_hand/state/left_hand --once

# ZMQ手柄遥操
scp ~/WireConnect_ws/tools/zmq_hand_control.py ubuntu@172.16.17.214:~/
ssh ubuntu@172.16.17.214 "source /opt/ros/humble/setup.bash && python3 ~/zmq_hand_control.py"

# 直接控制 (JointState, position=0~1)
source ~/WireConnect_ws/install/setup.bash && ros2 topic pub --once /inspire_hand/ctrl/left_hand sensor_msgs/msg/JointState \
  '{name: ["1","2","3","4","5","6"], position: [0.5, 0.5, 0.5, 0.5, 0.5, 0.5]}'
```

手指ID: 1=小指 2=无名指 3=中指 4=食指 5=拇指弯曲 6=拇指旋转
