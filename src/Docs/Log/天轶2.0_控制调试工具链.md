## 0. 机器人自检 & body_control 启动

```bash
# === 正常自检 ===
# 开机后遥控器按A, 等待音效+蓝绿灯常亮

# === 跳过自检 ===
sudo systemctl stop proc_manager.service

# 跳过手部自检
cat > /home/ubuntu/data/param/u2c_sn.yaml << 'EOF'
auto_init: true
enable_check_ready: true
enable_arms: true
enable_legs: true
enable_hands: true
enable_6dof: true
enable_head: true
enable_waist: true
u2c_sn:
  - 31F10005D39
  - 31F10005D3E
  - 31F10005F90
  - 31F10005C4C
EOF

# 手动启动 body_control (终端1, 保持运行)
cd /home/ubuntu/ros2ws
source install/setup.bash
ros2 launch body_control body.launch.py
```

### 1.4 xarmcontroldebug — XARM 控制器交互

```bash
source ~/WireConnect_ws/ROS/robot_pkgs/XARM/install/setup.bash    # 提供 eai_manipulator_msgs
ros2 run xarm_debug xarmcontroldebug
```

| 命令 | 说明 |
|------|------|
| `l` | 列出所有控制器 |
| `a <name>` / `d <name>` | 激活 / 停用 |
| `jL <7f>` / `jR <7f>` | 关节空间 (rad) |
| `cL/cR <xyz qxyzw>` | 笛卡尔空间 (m + 四元数) |
| `eb <x z pitch yaw>` | 腰腿笛卡尔 |
| `frame <name>` | 切换笛卡尔参考系 |
| `mode <0-3>` | 0柔顺 1速度 2重力补偿 3位置环 |
| `arm enable` | 手臂硬件使能 |

## 2. XARM 启动 & 控制器

```bash
# 机器人 (终端2)
source /opt/ros/humble/setup.bash
source /home/ubuntu/XARM/install/setup.bash
ros2 launch tianyi2_bringup tianyi2.launch.py hardware:=real

# 杀 RSP (避免 /tf 冲突)
pkill -f robot_state_publisher

# 硬件使能
ros2 service call /EAIHardware/set_arm_mode eai_manipulator_msgs/srv/Mode "{mode: 3}"
ros2 service call /EAIHardware/set_arm_enable std_srvs/srv/SetBool "{data: true}"
ros2 service call /EAIHardware/set_head_enable std_srvs/srv/SetBool "{data: true}"

# 激活关节控制器 (逐条, 避免一次性失败)
ros2 control switch_controllers --activate jointspace_arm_L_controller
ros2 control switch_controllers --activate jointspace_arm_R_controller

# 确认
ros2 control list_controllers | grep -E "jointspace_arm|joint_state"
```

## 5. 灵巧手控制

```bash
# 读取状态
ros2 topic echo /inspire_hand/state/left_hand --once

# 控制 (JointState, position=0~1 百分比, 6关节)
ros2 topic pub --once /inspire_hand/ctrl/left_hand sensor_msgs/msg/JointState \
  '{name: ["1","2","3","4","5","6"], position: [0.5, 0.5, 0.5, 0.5, 0.5, 0.5]}'

# 右手
ros2 topic pub --once /inspire_hand/ctrl/right_hand sensor_msgs/msg/JointState \
  '{name: ["1","2","3","4","5","6"], position: [0.5, 0.5, 0.5, 0.5, 0.5, 0.5]}'
```

手指ID: 1=小指 2=无名指 3=中指 4=食指 5=拇指弯曲 6=拇指旋转

## 8. xrocs 使用

xrocs 是天轶2.0 Pro 的 Python SDK，提供 Station(robot+hand+camera+force_sensor) 统一接口。

### 安装

```bash
pip install ~/WireConnect_ws/xrocs/eai/syseai/xrocs-3.1.6.1-cp310-cp310-linux_x86_64.whl
```

### 架构

```
Station
├── Robot (TienYi2Pro)
│   ├── mc.direct_ctrler → /jointspace_commands_L, /endposetarget_L
│   ├── mc.moveit_ctrler → MoveIt 规划
│   └── pin_kine → Pinocchio 正运动学
├── Hand (InspireHand3Ros2)
│   └── /inspire_hand/ctrl/left_hand, state
├── Camera (OrbbecCameraRos2)
│   └── /ob_camera_head/color/*, depth/*
└── ForceSensor
    └── /arm_6dof_left, /arm_6dof_right
```

### 基本用法

```python
from xrocs.entity.station import Station

station = Station("tianyi2_pro")
station.connect()

# 读状态
obs = station.get_obs()

# 关节控制
station.robot.mc.direct_ctrler.pub_jointspace_commands_l([0.0, 1.18, 0.0, -1.3, 0.0, -0.13, 0.18])

# 笛卡尔控制 (需 endpose controller active)
station.robot.mc.direct_ctrler.pub_endposetarget_l(x=0.35, y=0.20, z=-0.10, qx=0,qy=0,qz=0,qw=1)

# 手控制
station.hand.left.sync_target_joint([0.5, 0.5, 0.5, 0.5, 0.5, 0.5])

# 相机
rgb, depth = station.camera.read()
```

### 底层不依赖 xrocs 的直控 (已验证可用)

```bash
# 手臂
ros2 topic pub --once /arm/cmd_pos bodyctrl_msgs/msg/CmdSetMotorPosition ...

# 手
ros2 topic pub --once /inspire_hand/ctrl/left_hand sensor_msgs/msg/JointState ...

# 笛卡尔 (需 XARM)
ros2 topic pub --once /endposetarget_L eai_manipulator_msgs/msg/ArmTargetPose ...
```
