# 模仿学习 — 插入动作数采方案

> 草稿纸，逐步细化。每次跑命令前读一遍。

## 目标

采集"左手持线缆 → 插入 USB 口"的完整动作数据，用于训练插入动作的模仿学习模型。

## 硬件配置

- 左手: 已抓取线缆，悬在插头上方
- 右手: 刚性悬停，腕部相机斜向下拍摄插头
- 头部: 埋头看桌面
- 身体: 上升到固定高度

## 初始化流程

1. 身体上升到指定高度（waist_pitch 调整）
2. 头部转到预设角度（pitch ~25° 看桌面）
3. 右手规划到固定位姿（mode 3 位置控制），斜向下拍摄插头区域
4. 左手预设到插头上方（mode 3），手中已有线缆
5. 确认三路相机画面正常

## 录制流程

1. 左手切换 mode 2（重力补偿），手可以自由拖动
2. 右手保持 mode 3（刚性悬停）
3. 开始录 rosbag
4. 操作者拖动左手做插入动作
5. 停止录制
6. 左手切回 mode 3
7. 保存/丢弃

## 录制数据

| 信号 | 来源 | 频率 |
|------|------|------|
| 左腕相机 RGB | /camera_wrist_left/.../image_rect_raw | 30Hz |
| 右腕相机 RGB | /camera_wrist/.../image_rect_raw | 30Hz |
| 头部相机 RGB | /ob_camera_head/color/image_raw | 30Hz |
| 左手 TCP 位姿 | TF waist_yaw_link → left_tcp_link | 50Hz |
| 左手六维力 | /arm_6dof_left | ~100Hz |

不采手指（不动）。不采右手位姿（不动）。不实时切分 obs/act。

## 关键设计决策

### 身高一致性

身高固定 → 训练和部署保持相同身高 → 不影响模型。不需要在不同身高下采集。

### 多插头顺序

YOLO 无法可靠检测 USB 口 → 放弃视觉定位插口。模型从腕部相机画面隐式学习插口位置：

- 腕部相机紧贴末端，插口在画面中清晰可见
- 手拖到不同口上方的画面不同 → 模型学会根据画面判断"该往哪插"
- 不需要显式输入目标位置
- 每个口单独录 demo，部署时依次对准后执行
